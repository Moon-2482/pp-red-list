# Online Car Rate List 🚗

A fast, mobile-friendly **rate-list web app** for a print shop — customers can browse car branding / vehicle-graphics rates online instead of asking on WhatsApp.

- 📱 Installable PWA (works offline after first load)
- 🖨️ Built for PRINT POINT's real rate cards

Just open `index.html` in a browser, or deploy the folder to any static host.
